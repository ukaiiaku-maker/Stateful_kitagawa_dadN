# Peak S–N provisional visualization package

Endpoint: first captured front after a stable spatial seed. The elementary-attempt curve describes the conserved global cleavage clock; it is not the front-capture curve. Filled branch markers are captures and open right-pointing markers are finite administrative right-censors, never arrests.

Representative end states: captured/censored B001/B000 at 2500 and 2250 MPa, and captured B004/long-censored B005 at 1500 MPa. All figures are post-processed from existing summaries and terminal arrays. No simulation or image sequence is produced.

Fixed context: Peak, 300 K, R=0.1, 1000 Hz, ideal smooth 600 µm-radius blunt notch, one 10 µm correlated front segment, stress axis = sigma_a, no specimen-width scaling, no microflaw calibration.
